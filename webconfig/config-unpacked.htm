Desk

Connect to see your monitor layout.

Drag a label to move a computer; drag Main onto its last numbered monitor to flip it. The snapped drop is checked while you drag. Click a computer to see its settings below. Along-seam offsets are stored in the Segment Start and End values under Advanced.

Save, then try the layout while this page stays connected. Wait for the helper to say “Connected and paired — config mode” for correct multi-monitor hops. If it says “Device in config mode”, Exit before testing multi-monitor hops. Config mode reboots on entry and Exit, and ends automatically after five minutes.
